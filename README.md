# Chrome 侧边栏营销自动化插件

为营销人员提供的 Chrome 浏览器插件，帮助快速跨平台搜索相关讨论、批量回复评论。

## 核心能力

✨ **一键关键词搜索** - 输入预设关键词，自动跳转平台搜索结果  
🔥 **热度智能排序** - 按评论、点赞、分享自动排序最热讨论  
💬 **快速回复** - 在侧边栏草拟回复，后台自动打开目标视频、填充评论并按设置发送（利用浏览器登录身份）  
📝 **本地备忘录** - 管理回复模板，一键复制到侧边栏  

## 快速开始

### 安装
```bash
# 克隆仓库
git clone <repo-url> && cd chrome-marketing-sidebar

# 安装依赖
npm install

# 构建插件
npm run build
```

### 加载到 Chrome
1. 打开 `chrome://extensions/`
2. 启用"开发者模式"
3. 点击"加载已解压的扩展"，选择 `dist/` 目录

### 使用示例
1. 访问 Twitter.com，点击侧边栏图标
2. 输入关键词（如 "AI"），点击搜索
3. 查看排序后的热门讨论
4. 选择一条推文，在侧边栏输入回复内容
5. 点击"一键后台填充并发送"，插件在后台打开目标视频并完成填充/发送
6. 如关闭自动发布，则到已打开的视频页手动确认发布

## 隐私与安全

✅ **完全本地运行** - 所有数据存储在浏览器本地，无后端服务  
✅ **无密码存储** - 仅利用浏览器已登录会话，不存储任何凭证  
✅ **可选自动发布** - 默认可后台填充并发送，也可关闭自动发布后手动确认  
✅ **遵守 ToS** - 不爬虫、不绕过身份验证、不违反平台条款  

## 已知限制

- 第一版仅支持 Windows/Mac Chrome（Firefox/Edge 后续支持）
- 需要用户事先登录相关平台
- 大页面下 DOM 解析可能有延迟（优化中）
